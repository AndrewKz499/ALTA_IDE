# Dropdown

AltaIDE Dropdown, Figma Component Set `185521:27721`.

## Preview
▶ [Открыть живой Preview Dropdown](https://andrewkz499.github.io/ALTA_IDE/components/dropdown/preview.html)

## Sizes
`L` — 248 px; `M` — 162 px. Control height — 28 px, полный компонент с hint — 46 px.

## States
`Default`, `Selected`, `Hover`, `HoverFilled`, `Focused`, `FocusedFilled`, `Invalid`, `Hover_Invalid`, `Focused_Invalid`, `Loading`, `Disable`.

Interactive preview открывает список, позволяет выбрать option и закрывается по Escape/outside click. Используются semantic tokens `--dropdown-*` и `--dropdown-open-*`; стрелка построена по точному vectorPath Figma. Light/Dark меняются только tokens.
