## Item variants
- `Default / Stroke`
- `Hover / Stroke`
- `Active / Stroke`
- `Info / Menu`

Interactive preview фильтрует список по введенному фрагменту, поддерживает ↑/↓ и Enter. Совпавший фрагмент подсвечивается semantic token `--autocomplete-item-fill`. Используются `--autocomplete-item-*`, `--autocomplete-info-*`, `--autocomplete-*`; кодовая часть — JetBrains Mono 14/20, дополнительная информация — Rubik. Light/Dark меняются только semantic tokens.
