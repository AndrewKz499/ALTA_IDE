# Clipboard and Hints

Два связанных вспомогательных сообщения AltaIDE DS: `AltaIDE/Сlipboard` (189×24) и `AltaIDE/Hints` (212×24).

## Preview
▶ [Открыть живой Preview](https://andrewkz499.github.io/ALTA_IDE/components/clipboard-and-hints/preview.html)

Оба используют Rubik 12/16 и semantic tokens `--clipboard-and-hint-*`. Clipboard используется как краткий status/toast после копирования, Hints — как tooltip/hint. Light/Dark меняются только через tokens.
