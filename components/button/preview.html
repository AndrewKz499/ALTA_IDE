Button

Кнопка AltaIDE DS. Канонический путь: components/button/.

Назначение

Button используется для запуска пользовательского действия. Компонент имеет одну DOM-структуру и один набор CSS-правил для обеих тем.

Размеры и варианты

  • data-size="l" — размер L, типографика 14/20.
  • data-size="m" — размер M, типографика 12/16.
  • data-icon="none" — без иконки.
  • data-icon="left" — иконка слева.
  • data-icon="right" — иконка справа.
  • data-icon="only" — только иконка; требуется доступное имя через aria-label или aria-labelledby.

Темизация

Light и Dark не являются отдельными версиями компонента. Переключатель в правом верхнем углу меняет document.documentElement.dataset.theme между light и dark. Button использует семантические переменные --buttons-*, а их значения поступают из tokens/tokens.css.
