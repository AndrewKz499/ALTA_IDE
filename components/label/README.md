# Label

Базовый текстовый label AltaIDE DS. Figma node `201332:2291`.

## Preview

▶ [Открыть живой Preview Label (Light / Dark)](https://andrewkz499.github.io/ALTA_IDE/components/label/preview.html)

## Спецификация

- Figma: 36×20 px для текста `Label`;
- типографика: Rubik Regular 14/20;
- цвет: semantic token `--labels-content`;
- компонент не имеет variants/states и не требует JavaScript.

```html
<span class="ds-label">Label</span>
```

Light/Dark меняют только semantic tokens; DOM компонента остается единым.
